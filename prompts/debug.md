# Debugging & Bug Analysis Instructions

Analyze the reported bug, error log, or stack trace and locate the issue in the codebase. Provide a structured response:

## 1. Root Cause Analysis
Explain *why* the bug is occurring, referencing the specific files, lines of code, and states that lead to the failure. Keep this explanation under 3 sentences.

## 2. Recommended Fix
Provide the exact code change needed to fix the bug. 
- Use a git-style diff block to show the change.
- Explain any side-effects or implications of this fix.
- Keep the solution focused and minimal. Do not rewrite surrounding code unless necessary.
